# 相册拖拽与人物预览 · 2026-11-08

- 相册以显式多列瀑布流排版，列数根据可用宽度计算，桌面最多五列、手机两列。避免 CSS columns 在图片高度变化后集中使用前几列。
- 默认人物预览：仅对高宽比大于 1.4 的官方海报裁取上 2/3，裁后最后 18% 逐渐透明。完整原图模式可切回；查看、下载原始相册图片不裁切。
- 新增原比例并排模板；保留四宫格、九宫格、长条三连和主图加四小图。
- 拼图按独立格子保存，空位用 null 保留；拖到任意空位可放置，与已占用格子拖动互换。删除图片也不挤压其他位置。换到较小模板时，优先将超出位置的图片放入空位；容量不足时显示提示，保留未容纳图片。
- 支持鼠标与手机触摸直接拖动、320ms 格子换位与 220ms 落位动画；关闭应用动画时跳过动效。保留 Alt + 方向键和列表箭头作为键盘操作方式。
- 模板、图片显示和画面模式均使用统一的深蓝金色选择组件，支持上下键、Home/End、Enter、Escape 与点击外部关闭。
- ArtImage、CollageEditor、CollageCanvas 共用布局、裁切和等比缩放规则。PNG 保存与屏幕上的空位、位置和渐隐一致。预览编号和移除按钮不进入成品。

验证：album-editor 23 项、album-fit 11 项、既有 e2e 14 项通过；生产构建通过。桌面使用四张真实海报检查横向排列，手机检查两列与触摸拖动。截图和导出样例保存在本机 QA 输出目录。

入口：`src/views/AlbumView.vue`；公共组件：`ArtImage.vue`、`CollageEditor.vue`、`StyledSelect.vue`；布局规则：`src/utils/collage.js`。
