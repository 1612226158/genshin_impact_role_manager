## 过程中修掉的问题

| 问题 | 根因 | 修复 |
|---|---|---|
| Vite 8 构建直接失败 | Rolldown 不支持 `manualChunks` 对象写法 | 移除该配置，靠路由级动态 import 分包 |
| 卡片立绘不显示 | 最初怀疑懒加载，实为 `mix-blend-mode` 在无头环境不合成 | 放弃混合模式，卡片底色直接取立绘自带浅灰底（#F7F5F4），跨浏览器更稳 |
| 生日卡无立绘 | `roundRect` 未 import，异常被空 catch 吞掉 | 补 import；catch 增加 console.warn 防止再被静默吞掉 |
| 无改动保存也记一条变更 | 编辑器丢了基础数据的 `story.summary` 字段 | `loadIntoForm` 保留 `summary` |
| 拼图裁掉头部 | `cover` 居中裁切竖长立绘 | 裁切基准点偏移到 16% 高度处 |
| 生日卡选中为空 | 当天无角色过生日时无默认选中 | 回退选中最近生日的角色 |
